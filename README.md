# summer-chores

This project was created as part of Code: You's Web Development course.

There are three versions of roughly the same script. In each one, the user can provide a person's name. Using async methods, the script will simulate the person doing their summer chores one after another. During each step there's a chance the person "falls asleep" and thus doesn't continue their chores.

The three versions are:
* Callbacks - `callbackVersion.js`
* Promises - `promiseVersion.js`
* Async/Await - `asyncAwaitVersion.js`

To run the file with an argument, use `node <file-name> <person-name>` in the terminal.
